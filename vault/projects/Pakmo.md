## Client Landing Page

[Pakmo.co](https://pakmo.co/) is a middle-man shipping service. I built out the user landing page to introduce new users to a sales rep.

## Client Application

Built the client application to track inventory items needing to be sent to Pakmo warehouses. Used integrations with Zenventory and Shipstation APIs to surface current inventory numbers.

## Automation Scripts

Built scripts to scan orders and client user data for fraud detection and flag suspicious orders.
